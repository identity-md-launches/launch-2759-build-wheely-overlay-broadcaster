Put WHEELY on air

Each widget is a transparent browser source. Your video stays in the scene underneath it.

  1. Choose your widget

    Pick a preview, adjust its style, then select Copy source URL.

  2. Add a Browser source in OBS

    In Sources, select + → Browser. Paste the URL. Set Width to 1920 and Height to 1080; use 30 FPS.

  3. Keep it above your video

    Leave Custom CSS empty. The page is already transparent. Keep “Shutdown source when not visible” and “Refresh browser when scene becomes active” off to preserve the log.

Using vMix?

Add Input → Web Browser. Paste the same URL and use a 1920 × 1080 input with transparent background. Add it as an overlay above your camera.

For a 1280 × 720 broadcast, keep the source at 1920 × 1080 and fit it to the canvas. A failed request keeps the last value and shows its stale age.
